Microsoft lanza un parche urgente para aplicaciones y servidores: qué corrige el fallo de Brotli

27 de octubre de 2026

Microsoft ha publicado una actualización de seguridad fuera de banda (OBB, por sus siglas) para .NET 8, .NET 9 y .NET 10, así como para la tercera versión candidata de .NET 11. Acorde a la información compartida por la compañía, el parche está distribuido fuera del calendario habitual de actualizaciones y corrige varias vulnerabilidades que pueden comprometer la seguridad de las aplicaciones y los sistemas que utilizan estas tecnologías, por ello, Microsoft recomienda instalar las nuevas versiones lo antes posible. Uno de los fallos corregidos afecta al algoritmo de descompresión Brotli, utilizado para procesar determinados datos comprimidos. Identificada como CVE-2026-111497, esta vulnerabilidad puede permitir que un atacante sin autenticar lea o modifique la memoria de un proceso, teniendo en cuenta que entre sus posibles consecuencias figuran la exposición de información, la interrupción del funcionamiento de un servicio y la obtención de privilegios elevados.

Solución aplicada

Microsoft detalla varios pasos para instalar las correcciones de seguridad en función de cómo se ejecuten o distribuyan las aplicaciones:

  • Aplicaciones que utilizan el entorno de ejecución instalado en el sistema: Es necesario instalar la versión actualizada de .NET correspondiente a la aplicación y reiniciarla para aplicar los cambios.
  • Aplicaciones autónomas: Deben recompilarse y publicarse de nuevo con el entorno de ejecución actualizado. Instalar una versión más reciente de .NET en el equipo no actualiza automáticamente la que está incluida en la propia aplicación.
  • Aplicaciones en contenedores: Hay que reconstruirlas y desplegarlas de nuevo utilizando las imágenes de contenedor de .NET actualizadas.
  • Entornos que compilan .NET desde el código fuente: Deben descargar los artefactos de compilación actualizados para la versión correspondiente y reconstruir los paquetes para incorporar la corrección relacionada con las propiedades de los archivos TAR.
  • Usuarios de ASP.NET Core en .NET 8 y .NET 9 que utilizan archivos TAR: Hay que actualizar la instalación con el archivo TAR del entorno de ejecución de ASP.NET Core correspondiente a su versión, incluso si no compilan .NET desde el código fuente.




SEIDOR obtiene la AWS Migration & Modernization Competency

27 de octubre de 2026

SEIDOR y AWS, una colaboración de éxito

La obtención de la AWS Migration and Modernization Competency posiciona a SEIDOR como AWS Partner con experiencia especializada para ayudar a los clientes a adoptar la nube y transformar sus aplicaciones, reducir costes de licencias, optimizar costes operativos y mejorar rendimiento, agilidad y resiliencia.

La obtención de la AWS Migration and Modernization Competency se suma al estatus AWS Premier Tier Services Partner y a la AWS DevOps Competency, reforzando su especialización en AWS. La relación de SEIDOR con AWS refleja un compromiso sostenido con el desarrollo de capacidades avanzadas en cloud, automatización, operaciones, migración y gestión de entornos tecnológicos a escala. Según Eduard Bonet, Director de Cloud & IT Infrastructure en SEIDOR, “la AWS Migration and Modernization Competency confirma la madurez de nuestra práctica cloud y la capacidad de nuestros equipos para abordar migraciones de gran volumen con una metodología contrastada». El directivo también constata que, «para nuestros clientes, supone poder avanzar hacia la nube con el soporte técnico de SEIDOR como AWS Partner validado y acceder a herramientas, beneficios y programas específicos que les permiten afrontar estos proyectos con mayor seguridad, planificación y continuidad operativa”.





Consejos para comprobar que tus copias de seguridad funcionan y van a ser útiles

25 de cotubre de 2026

Cómo verificar las copias de seguridad

Puedes hacer copias de seguridad de los archivos de tu móvil, del ordenador o de cualquier otro dispositivo. Esto puede incluir documentos importantes que puedas necesitar en algún momento. Por ello, es clave que esa copia realmente funcione bien, esté actualizada y bien configurada.


Contar con copias de seguridad, es algo que recomendamos continuamente. Es importante para evitar problemas en caso de sufrir ataques informáticos, como es el ransomware. También es fundamental de cara a acceder a archivos desde otros dispositivos o incluso poder liberar espacio de ciertos aparatos. Una opción es la de utilizar un ordenador antiguo para ello. Pero, ¿es una buena alternativa?

Otro problema que puedes tener, es que ese sistema que utiliza el equipo, se quede obsoleto. Puede tener vulnerabilidades, las cuales podrían ser aprovechadas por los piratas informáticos y robar datos personales, contraseñas o tomar el control del dispositivo. Lo ideal es tener siempre las últimas versiones instaladas. Al ser un equipo antiguo, es posible que no lo uses frecuentemente, por lo que podría quedarse obsoleto. Pero también puede pasar que, por limitaciones de hardware, ya no reciba parches de seguridad.
